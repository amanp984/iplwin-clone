# CategoryNav Specification

## Overview
- **Target file:** `src/components/sites/iplwin/home/CategoryNav.tsx`
- **Interaction model:** Click-driven category and provider tab switching
- **Computed Styles:**
  - Background: `#1A1A1A`
  - Active Tab: Background `#D1AE52`, text `#0A0A0A`, font-weight `700`, rounded `8px`
  - Inactive Tab: Background `#262626`, text `#999999`, hover text `#FFFFFF`, rounded `8px`
  - Sub-provider Chips: Horizontal scrollable strip with rounded chips, active chip border `1px solid #D1AE52`
