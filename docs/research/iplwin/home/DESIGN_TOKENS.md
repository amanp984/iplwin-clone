# Design Tokens: IPLwin (iplwin.in)

## Color Palette

### Backgrounds
- `--bg-primary`: `#0A0A0A` (Deepest canvas background)
- `--bg-secondary`: `#1A1A1A` (Cards, navbar, sidebar, drawers, modal background)
- `--bg-tertiary`: `#232323` (Active category tabs, input backgrounds)
- `--bg-elevated`: `#262626` (Hovered cards, dropdowns)
- `--bg-table`: `#0A0A0A`
- `--bg-bottom-nav`: `#0A0A0A` / `#1E1E1E`

### Primary & Brand Colors
- `--primary-gold`: `#D1AE52` (Brand signature gold)
- `--primary-gold-rgb`: `209, 174, 82`
- `--primary-gold-hover`: `#E0BE63`
- `--primary-gold-dark`: `#C39949`
- `--gold-gradient-top`: `#E9CA78`
- `--gold-gradient-bottom`: `#C39949`
- `--gold-gradient`: `linear-gradient(180deg, #E9CA78 0%, #C39949 100%)`
- `--gold-btn-gradient`: `linear-gradient(90deg, #E9CA78 0%, #D1AE52 50%, #C39949 100%)`

### Accent Colors
- `--accent-green`: `#04BE02` (Wins, active badges, success states)
- `--accent-red`: `#EA4E3D` (Hot tags, live indicators, critical alerts)
- `--accent-orange`: `#FFAA09` (Jackpot counters, VIP badge highlights)
- `--accent-purple`: `#C609FF` (Special game event tags)
- `--accent-blue`: `#368DEC` (Notice badges, link highlights)

### Borders & Dividers
- `--border-primary`: `#333333` (Standard card & divider borders)
- `--border-gold`: `rgba(209, 174, 82, 0.4)` (Active card / highlight borders)
- `--border-muted`: `#2A2A2A`

### Typography & Text Colors
- `--text-white`: `#FFFFFF` (Primary titles, amounts, prominent text)
- `--text-lead`: `#E3E3E3` (Secondary headings, body copy)
- `--text-muted`: `#999999` (Labels, inactive tab titles, subtitles)
- `--text-subtle`: `#666666` (Timestamps, footnotes, placeholders)
- `--text-gold`: `#D1AE52` (Highlighted text, links, prize amounts)
- `--text-dark`: `#0A0A0A` (Text on gold buttons)

## Typography

- **Font Family**: `Inter`, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Font Sizes**:
  - `xs`: 11px / 0.6875rem
  - `sm`: 12px / 0.75rem
  - `base`: 14px / 0.875rem
  - `md`: 15px / 0.9375rem
  - `lg`: 16px / 1rem
  - `xl`: 18px / 1.125rem
  - `2xl`: 22px / 1.375rem
  - `3xl`: 28px / 1.75rem
  - `jackpot`: 36px / 2.25rem (tabular numbers, bold)

## Spacing & Layout
- Desktop Max Width: 1280px (or fluid with max-width containment)
- Mobile Viewport: 390px - 450px centered container or full fluid
- Card Border Radius: 8px to 12px
- Button Border Radius: 6px to 20px (pill)
- Grid Gap: 10px to 16px
